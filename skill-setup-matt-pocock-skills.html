Skill card

setup-matt-pocock-skills

  • Learning outcome 1: Make a repository agent-ready: one-command checks, skills at project scope, AGENTS.md as pointers, a glossary and a standards file.

The pain point

The skills do not know your tracker, your labels or your doc layout. Matt Pocock says: "people ask me all the time, how do I make my skills work with Jira, work with beads, work with linear?" Without setup the skills guess where issues go and apply labels your tracker does not have.

What the skill does

It records for one repo where issues live, what the triage labels are called and where the domain docs sit. It writes these as markdown files under docs/agents/, so each repo has its own setup.

When to skip it

  • You work in a repo that is already set up, and the other skills already find your issues and labels. The skill is for a repo that has not been set up yet, once per repo.
  • You want to change how the other skills behave, such as their question style or tone. The skill is for the tracker, the labels and the doc layout only.

Where the course uses it

  • Day 1, 10:45, lab 2, one-command build and test. You run it once, in your stack repo.
