Skill card

triage

  • Learning outcome 3: Frame work as a problem with a reproduction, and triage a backlog into a ready-for-agent queue.

The pain point

You have a backlog, and nothing in it is marked as ready for an agent. Matt Pocock says: "you will often need to triage other people's ideas to figure out if they're good or not".

What the skill does

It recommends a state for each issue and applies nothing until you tell it to. For a ready-for-agent issue it writes an agent brief. For a rejected feature request it writes a record in .out-of-scope/.

When to skip it

  • You wrote the issues yourself. The skill is for incoming issues that other people raised.
  • You have a confirmed bug and need its root cause. The skill is for sorting issues, not for finding the cause of a bug.

Where the course uses it

  • Day 1, 15:00, lab 4, problem to queue. You triage a messy backlog and leave 5 ready-for-agent issues and 1 out-of-scope record.
