Skill map

  • 19 skills, Days 1 to 3

This map shows the 19 skills the course teaches. An arrow means one skill calls another while it runs. A dashed line means a skill needs the config files that setup-matt-pocock-skills writes, and tells you to run that skill first. The skills on the watch list are left out, with their arrows.

How to read it

  • A Day 1 skill.
  • A Day 2 or Day 3 skill.
  • Calls the other skill while it runs.
  • Needs the config files from setup-matt-pocock-skills.
  • Each box gives the day and start time of the session that teaches the skill. "Only you start it" means you type its name. "You or the agent" means the agent can also start it when the task fits.

The map

What the map tells you

  • A few skills carry the rest. grilling and domain-modeling are each called by three skills. codebase-design, tdd and code-review are each called by two.
  • A skill that only you can start is never called by another skill. No solid arrow ends at one. You type those skills yourself.
  • Day 1 skills come back later. domain-modeling runs inside grill-with-docs on Day 2 and improve-codebase-architecture on Day 3. codebase-design runs inside tdd on Day 2 and improve-codebase-architecture on Day 3. writing-for-agents runs inside retro on Day 3. The config files from setup-matt-pocock-skills are needed again on Day 2 and Day 3.

Source: the skills repo github.com/mattpocock/skills at commit 5863806. Each arrow and each dashed line traces to a line in a SKILL.md file at that commit.
