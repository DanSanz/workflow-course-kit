Part 2, the hook and the CI workflow

  1. Part 2. Ask for the pre-commit hook.

    A pre-commit hook checks the staged files at each commit, and a commit that fails its check stops there. Your first commit in this part holds the fix of part 1 and runs the hook.

    Python

    Expect a hook that runs the date rule on the staged .py files.

    Add .githooks/pre-commit that runs scripts/pre-commit.ps1 in Windows PowerShell. It runs python -m ruff check --force-exclude on staged .py files only and exits 0 if none. No path guard. Add python -m ruff check . to scripts\check.ps1.
    .NET

    Expect a hook that checks the layout of the staged .cs files. The date rule needs a build, so it waits for the check command.

    Add .githooks/pre-commit that runs scripts/pre-commit.ps1 in Windows PowerShell. It runs dotnet format whitespace --folder --verify-no-changes --include on staged .cs files only and exits 0 if none. No path guard.

Part 4, the boundary check

  1. Part 4. Add the boundary check. It fails the check command if code breaks the rule in standards.md.

    The agent adds the package. You paste the contract that states which layers may depend on which.

    Python 
    Add import-linter==2.* to requirements-dev.txt and install it.

    Paste this at the end of pyproject.toml. Leave no blank line after the last ], or a hook that checks blank lines refuses the commit.

    [tool.importlinter]
root_packages = [
  "pipeline", "employer_reports",
  "late_contributions", "reconciliation",
  "valuation_extract", "member_service",
  "member_store", "feeds", "generated",
  "scheme_common",
]

[[tool.importlinter.contracts]]
name = "Imports point downwards"
type = "layers"
layers = [
  "pipeline",
  "employer_reports",
  "late_contributions | reconciliation | valuation_extract | member_service",
  "member_store",
  "feeds",
  "generated",
  "scheme_common",
]
    .NET 
    Add NetArchTest.Rules 1.3.2 to the unit test project.

    Paste this into a new file ArchitectureTests.cs there. Keep the indents and end with a new line.

    using MemberIngestion.Members;
using NetArchTest.Rules;
namespace MemberIngestion.UnitTests;

public sealed class ArchitectureTests
{
    const string N = "MemberIngestion.";
    // Known breaks, each with a reason.
    // Form: "Type -> Namespace".
    static readonly string[] Known = [];
    [Theory]
    [InlineData("Feeds", "Ingestion")]
    [InlineData("Feeds", "Reports")]
    [InlineData("Ingestion", "Reports")]
    [InlineData("Members", "Ingestion")]
    [InlineData("Members", "Reports")]
    [InlineData("Members", "Feeds")]
    public void Points_down(
        string from, string to)
    {
        var r = Types.InAssembly(
                typeof(Member).Assembly)
            .That()
            .ResideInNamespace(N + from)
            .ShouldNot()
            .HaveDependencyOn(N + to)
            .GetResult();
        var broken =
            (r.FailingTypeNames ?? [])
            .Where(t => !Known.Contains(
                $"{t} -> {to}"));
        Assert.Empty(broken);
    }
}
